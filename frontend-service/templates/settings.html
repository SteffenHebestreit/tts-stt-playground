      Lost your admin key?

      Recovery without this page
      • Delete settings/gateway.json in the app's dataset: the app YAML values apply from the next request on.
      • Create an empty file settings/SAFE-MODE: saved values are ignored until it is deleted. API keys stay in force.
      • Set ENABLE_SETTINGS_UI: false in the app YAML: this page becomes read-only and saved values are ignored.
      • Delete settings/keys.json: the keys made here are gone and the API follows the app YAML key again.

      Set in the app YAML, not here

      These need the container to be created again, or are controls a web page must not hold over itself. Change them in the app YAML (TrueNAS: Apps, tts-stt, Edit).

      • Release and updates: IMAGE_TAG, PULL_POLICY, IMAGE_REGISTRY, NEMO_IMAGE_SUFFIX, DIUN_*
      • GPU: GPU_DEVICE_ID
      • Web UI port and bind address: FRONTEND_PORT, FRONTEND_BIND_ADDR
      • Data folder: APP_DATA_DIR
      • Which optional containers are installed: their profiles: lines
      • The host check's off switch: ALLOWED_HOSTS='*'
      • Any web page may call the API: ALLOWED_ORIGINS='*'; cookies for it: ALLOW_CREDENTIALS
      • The deployment key: API_KEY
      • This page's own switches: ENABLE_SETTINGS_UI, SETTINGS_LOCKED_KEYS
